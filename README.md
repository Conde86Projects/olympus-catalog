# olympus-catalog

Feed da fonte própria do player Olympus, publicado pelo GitHub Pages.

| Arquivo | Para quê |
| --- | --- |
| `feed.json` | Catálogo definitivo, só mídia autorizada. |
| `feed-smoke.json` | Só testes técnicos de HLS. Nunca é o catálogo público. |
| `media/` | Vídeos hospedados aqui. |
| `images/` | Miniaturas. |
| `ATTRIBUTIONS.md` | Licenças e créditos de cada mídia. |

Endereço no app: `https://conde86projects.github.io/olympus-catalog/feed.json`
